不要鸽我 · CodePen V11 交互设计稿

最快使用方式
1. 打开 dont-ghost-me-codepen-v11.txt。
2. 全选并复制里面的全部代码。
3. 回到 CodePen，点击 index.html。
4. 在编辑区按 Ctrl+A 全选原内容，再粘贴新代码。
5. style.css 和 script.js 不需要修改，单文件版已经包含全部样式和交互。

文件说明
- dont-ghost-me-codepen-v11.txt：最适合直接粘贴到 CodePen 的单文件版。
- dont-ghost-me-codepen-v11.html：可直接用浏览器打开的同内容版本。
- index.html、style.css、script.js：适合后续交给前端成员的分文件版。
